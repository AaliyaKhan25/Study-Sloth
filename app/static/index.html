A calmer way to study

Make room for more learning.

Study Sloth is a semester folder that fills itself. Drop in lectures, board photos, PDFs and lab code, and get back the notes, practice and records you'd otherwise write at the last minute.

What goes in, what comes out

Bring the material. Get the study set.

🎧

Lecture recording

Timestamped notes sorted by unit, plus flashcards, a quiz and likely viva questions.

📄

PDF reading

Section-by-section notes with page references, so long readings become short, checkable summaries.

🧪

Lab code and output

A finished lab record: aim, theory, procedure, code, output and conclusion, ready to print as PDF.

🧭

Syllabus and board photos

Everything organised by unit, with board formulas and diagrams placed into the right notes.

Lectures and labs feed each other: the theory in a lab record comes from your lecture notes, and your lab code becomes viva questions.

Honest by design

Your work stays yours.

Your output, not the model's

A lab record uses only the output you supply. Nothing is invented, and printing stays locked until you review the record and confirm you ran the code.

Notes you can check

Every point carries a timestamp or page number, so you can verify a small model's work against the source.

Private by default

Recordings, photos, PDFs and code are processed on your own computer and never uploaded.

Why open-source AI

It works offline, and you can swap the model.

Everything runs on a laptop with no internet and no cost per use. Because the models are open, switching one is a single setting, for example Qwen for Gemma, so you can compare them on your own notes. Built on Qwen3 and Qwen3-VL (Apache-2.0) through Ollama, faster-whisper (MIT) for transcription, FastAPI and SQLite.

Try it

Run it on your laptop.

ollama pull qwen3:4b-instruct
ollama pull qwen3-vl:4b-instruct
git clone https://github.com/AaliyaKhan25/Study-Sloth
cd Study-Sloth
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
set SLOTH_MODEL=qwen3:4b-instruct
python -m uvicorn app.main:app --port 8000

Then open http://localhost:8000. Built for a laptop with a 6 GB GPU. The set line is for Windows cmd; in PowerShell use $env:SLOTH_MODEL="qwen3:4b-instruct".
